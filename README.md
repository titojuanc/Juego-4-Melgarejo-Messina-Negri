# Juego-4-Melgarejo-Messina-Negri

Idea:
La idea es hacer un juego estilo tower defence mezclado con recolección de recursos, mejora de base y completar una historia.
Inspiración: Dont Bite Me Bro --> Link de descarga del juego: https://muifwego.itch.io/dont-bite-me-bro


Mini-tutorial:
- WASD para moverte
- RMB para apuntar, LMB para disparar
- LMB SOLO para pegar
- E para interactuar
- B para construir

Flujo:
Revisá el lugar, movete como quieras. Pegale a un par de objetos y fijate cómo se consiguen los materiales.
Construí un poco
Hacé la misión del npc de la base y de la ciudad
Vas a ver que el de la ciudad te pide una llave, y se consigue pescando
La caña se consigue matando al jefe
para encontrar al jefe vas a la mazmorra del norte
y eso sería.
